# CodinGamesRepo

Бот для игровой арены CodinGame: сетка, хвосты игроков, четыре направления.
На каждом ходу перебирает возможные ходы и выбирает тот, который даёт максимальную
контролируемую территорию.

## Стек

- C# / .NET
- Многопоточность не нужна: один ход — один расчёт
- BFS (multi-source) для оценки территории

## Как работает

1. `GameSimulator` читает состояние: размер поля, id игрока, позиции всех игроков.
2. `GameState` хранит сетку и признаки живых игроков, умеет клонироваться.
3. `Solver` перебирает 4 направления:
   - копирует состояние;
   - применяет ход;
   - считает размер территории через multi-source BFS (диаграмма Вороного).
4. Выбирает направление с максимальной территорией.

Дерево на несколько ходов вперёд не строится — зато решение дешёвое и устойчивое:
укладывается в лимит времени и не деградирует на больших картах.

## Структура

```
State/GameState.cs      сетка, игроки, валидация, клонирование
State/PlayerInfo.cs     координаты и флаг жизни
Sim/GameSimulator.cs    чтение ввода, обновление состояния, смерть игрока
Logic/Solver.cs         перебор ходов и оценка территории
```

## Как запустить

Репозиторий содержит только исходники бота, без `.csproj`:

1. Создай пустой консольный проект:

```bash
dotnet new console -n CodinGamesBot
```

2. Скопируй папки `State`, `Sim`, `Logic` в проект.
3. Замени `Program.cs` на цикл чтения ввода и вызова `Solver.FindBestMove(state)`.
4. Либо вставь классы в IDE CodinGame и запусти арену там.
